# Personal Portfolio

My developer portfolio site — responsive, accessible, and built from scratch with no framework.

**Live demo:** https://mstradsdev-portfolio.netlify.app

## Features

- Fully responsive, mobile-first layout
- Light/dark theme toggle with saved preference
- Accessible forms and keyboard navigation
- Working contact form via Netlify Forms

## Tech stack

- HTML5, CSS3 (Flexbox, Grid, custom properties), vanilla JavaScript
- Deployed on Netlify

## Running locally

Open `index.html` in a browser, or use a live-server extension for auto-reload.
